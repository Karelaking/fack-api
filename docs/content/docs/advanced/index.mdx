## Architectural Pillars

Fack API is designed around three core operational principles:

- **Non-Blocking Telemetry**: Telemetry and logs run asynchronously via Next.js background workers, ensuring zero overhead on mock response latency.
- **Database Portability**: Unified Drizzle ORM layer allows transparent execution across local SQLite, libSQL/Turso edge databases, and PostgreSQL.
- **Flexible Infrastructure**: Deploy as a single self-contained Docker container, a serverless cluster on Vercel, or a standalone Node.js process behind your preferred reverse proxy.

For configuration instructions, select one of the topics above or explore the [Mock Engine](/docs/mock-engine) documentation.
