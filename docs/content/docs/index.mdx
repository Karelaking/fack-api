Welcome to the official **Fack API** documentation. Fack API is a modern mock API engine and developer workspace designed for frontend developers, mobile engineers, and teams who need rapid, reliable backend mocks.

## Overview

Fack API combines visual node-based API composition with a streaming AI API Architect to let you design, test, and consume realistic mock services in seconds.

### Key Capabilities

- **Interactive Flow Canvas**: Graphically compose endpoints, routes, and responses using node-based visual routing.
- **Fack AI API Architect**: Generate production-grade, enterprise REST API designs and mock data from natural language specifications.
- **Dynamic Faker Synthesizer**: Realistic fake data generation supporting dozens of standard business domains.
- **Realtime Latency & Error Injection**: Simulate production conditions including latency jitter, 4xx/5xx error rates, and custom headers.
- **Isolated Documentation App**: Fully decoupled Fumadocs-powered documentation running side-by-side with your development environment.
