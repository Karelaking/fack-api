Fack API integrates the full power of **Faker.js**, giving you access to over 1,500 built-in data generators across 25+ domain categories. Instead of returning generic filler text like `"string"` or `"test"`, your mock endpoints return realistic names, valid email addresses, credit card numbers, geo-coordinates, and high-resolution images.

## Searchable Provider Selector

In the Edit Bar, each field features a data provider combobox selector:

- **Categorized Search**: Filter through providers by category or start typing any keyword (e.g., "email", "avatar", "price") to filter instantly.
- **Live Example Previews**: The selector displays live rendered sample values next to each provider name, allowing you to preview the format before assigning it.
- **Zero Client Overhead**: Provider metadata is pre-indexed on initialization, allowing sub-millisecond lookups without bundling the entire Faker.js engine into client-side bundles.

    - `internet.url` — Fully-qualified HTTPS URL (e.g., `"https://bright-summit.org"`)

    - `internet.password` — Alphanumeric password string (e.g., `"k8$Jv#92Lm"`)

    - `commerce.isbn` — Valid book ISBN string

  <Accordion title="Finance (Accounts, Currencies & Transactions)">

## How Providers Map to JSON Schema

When you assign a provider to a field, the Schema Builder annotates that property in the synthesized JSON Schema using the `x-faker` vendor extension:

```json title="schema-with-faker.json"
{
  "type": "object",
  "properties": {
    "userId": {
      "type": "string",
      "format": "uuid",
      "x-faker": "string.uuid"
    },
    "fullName": {
      "type": "string",
      "x-faker": "person.fullName"
    },
    "contactEmail": {
      "type": "string",
      "x-faker": "internet.email"
    },
    "walletBalance": {
      "type": "number",
      "x-faker": "finance.amount"
    },
    "registeredAt": {
      "type": "string",
      "x-faker": "date.past"
    }
  },
  "required": ["userId", "fullName", "contactEmail", "walletBalance", "registeredAt"]
}
```

### Runtime Evaluation

During an HTTP request, Fack API's mock engine feeds the schema to `json-schema-faker`. The engine intercepts each `x-faker` attribute and executes the matching Faker.js generator:

```json title="runtime-output.json"
{
  "userId": "c71a3962-95f3-42e1-a085-bfdbda01a550",
  "fullName": "Sophia Martinez",
  "contactEmail": "sophia.martinez@enterprise.org",
  "walletBalance": 1420.75,
  "registeredAt": "2024-03-12T14:48:32.190Z"
}
```

<Callout type="info">
When defining arrays of primitive items (such as tags or phone numbers), configure the **Item Provider** in the visual editor to bind `x-faker` directly to the `items` schema node.
</Callout>
